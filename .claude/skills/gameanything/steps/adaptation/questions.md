# Step questions — 问关键问题 (you, then her)
Entry: scenes and characters confirmed. Ask before you invent.
Do: one `questions` card, ordered by impact: overall scale, where places sit, things the game lacks (plants, animals) and how to map them, season / time, which name to use. Each item: the evidence from the text and a default in `hint`.
```yaml
kind: questions
key: plan-questions
title: 写方案之前想问你 4 件事（不答的按默认）
items:
  - {n: 1, text: 士兵岛做多大？, hint: 默认：岛 200×150 格，宅子在南端悬崖上（原文：「低矮方正的现代房子」）}
  - {n: 2, text: 第一版做哪几处？, hint: 默认：码头、宅子一楼、薇拉的卧室}
en: {title: "4 questions before the plan (unanswered ones use the default)"}
```
Exit: card sent, every item has a hint, she answered (partial is fine: the rest take the default).
Mistakes: asking in plain text; questions without defaults; asking things the text already answers.
