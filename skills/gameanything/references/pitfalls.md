# 容易做错的（都发生过）

- **用户说了话，你没回**：等待命令没挂上，或者你忙别的忘了回。用户只能切回终端叫你。
- **工作区里的意见你没看到**：现在都会进对话，但每次处理一版的意见时，还是要把试玩页的留言都看一遍。
- **截图和录像要和当前版本一致**：改了东西以后，旧截图、旧录像要重做（唱片机的歌名就是这样漏的）。
- **构建 agent 写的回放可能走不完**：要自己独立回放到底，不要只信它的报告。
- **生图的提示词里不要写对方没有的东西**（给不戴眼镜的人画上了眼镜）。新头像要先和照片并排看过。
- **功能按名字找不到入口**：做了一个页面，就要在流程里写清什么时候请用户去用它（这一份就是这么来的）。
